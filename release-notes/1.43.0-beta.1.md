# Contrôle de disponibilité des modules

**1.43.0-beta.1 · Bêta · 2026-10-20**

Ajout d’une politique de disponibilité administrée depuis le dépôt officiel. Elle permet de suspendre temporairement un module et d’expliquer la raison dans le client, sans supprimer les réglages du joueur.

## Disponibilité des modules

- Vérification au lancement puis chaque minute. Une restriction peut concerner toutes les versions compatibles ou une plage de versions.
- Les modules suspendus cessent leurs actions et affichent « Désactivé par l’administrateur » avec la raison. Les réglages personnels sont conservés et le minage ne redémarre pas automatiquement après réactivation.
- La dernière politique valide est mémorisée pour les lancements hors ligne. Les versions 1.42.1 et antérieures ne disposent pas de ce mécanisme.

## Administration

- Une page État des modules est accessible depuis la documentation. Les changements passent par un workflow GitHub réservé au propriétaire du dépôt ; aucun secret administrateur n’est livré dans le client.
- Cette préversion permet de vérifier le contrôle distant avant sa diffusion stable. Activez le mode développeur pour la recevoir via le programme de mise à jour.

# Documentation illustrée et mise à jour stable

**1.42.1 · Stable · 2026-10-20**

La documentation du Companion présente maintenant les interfaces en situation sur Minerite. Cette version permet aussi de tester le parcours de mise à jour depuis la première version stable, sans changement du code de jeu.

## Documentation

- Ajout de douze guides en français, avec recherche et captures agrandissables : installation, modules, recettes, wiki, menus du serveur, inventaire, HUD, apparence, thèmes, raccourcis, mises à jour et dépannage.
- Captures prises en jeu sur Minerite : hôtel des ventes, établi /craft, prestige, inventaire rempli et HUD.

## Passer de 1.42.0 à 1.42.1

- Au lancement du jeu, acceptez la mise à jour proposée, puis attendez la fin du téléchargement. Vous pouvez continuer à jouer.
- Le nouveau fichier sera installé après la fermeture du jeu et chargé au lancement suivant. Vos réglages sont conservés.
- Cette publication est stable : le mode développeur n’est pas nécessaire pour la recevoir. Le code de jeu est identique à celui de 1.42.0.

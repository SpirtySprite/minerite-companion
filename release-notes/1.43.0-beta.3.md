# Aperçu des shulkers dans les inventaires

**1.43.0-beta.3 · Bêta · 2026-10-20**

Correction de l’aperçu interactif des shulkers dans les interfaces d’inventaire et de stockage classiques.

## Correction

- Le maintien de Maj sur une shulker est désormais détecté dans l’inventaire du joueur et les coffres classiques, y compris le coffre de l’Ender lorsque son interface personnalisée est désactivée.
- Le chemin des infobulles classiques transmet maintenant l’objet survolé au système d’aperçu, comme le faisaient déjà les menus personnalisés.
- Le contenu reste limité aux données transmises par le serveur. Relâcher Maj ferme l’aperçu et restitue la position du pointeur.

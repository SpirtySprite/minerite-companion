# Le Companion arrive sur GitHub

**1.41.0-rc.1 · Bêta · 2026-10-20**

Le code source est désormais public, avec une compilation Gradle et un système de mise à jour soumis à votre confirmation.

## Code source

- Publication des sources Java, ressources et tests dans un dépôt dédié.
- Les outils Python, installateurs locaux, journaux et fichiers générés restent hors du dépôt.

## Mises à jour

- Une fenêtre propose de télécharger une nouvelle version ou de remettre la mise à jour à plus tard.
- Après acceptation, un installateur Java séparé attend la fermeture du jeu avant de remplacer le mod.
- Les réglages sont conservés et l’ancienne version est sauvegardée.

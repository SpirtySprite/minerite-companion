# Minecraft 26.2 et 26.3

**1.45.0 · Stable · 2026-10-21**

Le Companion est maintenant disponible pour Minecraft 26.2 et 26.3, avec un fichier adapté à chaque version du jeu. Les deux versions conservent le contrôle de disponibilité des modules.

## Compatibilité Minecraft

- Deux fichiers JAR distincts sont proposés : choisissez celui qui correspond à votre version de Minecraft. Le site permet de sélectionner 26.2 ou 26.3 avant le téléchargement.
- Adaptation des entrées clavier et souris au système SDL de Minecraft 26.3, y compris les raccourcis, les clics dans les inventaires et le pointeur des aperçus de shulkers.
- Adaptation du rendu des interfaces, des animations de pioche, des infobulles et des ressources générées aux nouvelles API de Minecraft 26.3.

## Mises à jour et modules

- Le programme de mise à jour sélectionne uniquement le fichier correspondant à la version de Minecraft en cours. Passer de 26.2 à 26.3 nécessite d’installer manuellement le fichier pour 26.3.
- Les restrictions de modules restent vérifiées au lancement puis chaque minute. Les réglages existants sont conservés.
- Le fichier pour Minecraft 26.2 inclut toujours Cosmetica. Sur 26.3, Cosmetica n’est pas embarqué tant qu’aucune version compatible n’est publiée ; le Companion fonctionne sans lui.

## Prérequis

- Minecraft Java 26.2 ou 26.3, Java 25 et Fabric API pour la même version de Minecraft. Pour 26.3, utilisez Fabric Loader 0.19.5 ou plus récent.
- Cette version prend en charge 26.2 et 26.3. Les versions suivantes nécessiteront une vérification de compatibilité avant d’être annoncées comme prises en charge.

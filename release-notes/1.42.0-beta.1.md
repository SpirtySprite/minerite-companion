# Des mises à jour à votre rythme

**1.42.0-beta.1 · Bêta · 2026-10-20**

Choisissez les versions proposées par le Companion et retrouvez les nouveautés dans un journal de versions commun au client et au site.

## Canaux de mise à jour

- Le Mode développeur est désactivé par défaut : seules les versions stables sont proposées.
- Activez le Mode développeur pour recevoir également les versions bêta.
- Chaque mise à jour demande votre accord avant le téléchargement et s’installe après la fermeture du jeu.

## Un vrai journal de versions

- Une nouvelle page dans le Companion présente les nouveautés, améliorations et correctifs de chaque version.
- Filtrez les versions stables et bêta, parcourez l’historique et consultez les notes depuis la fenêtre de mise à jour.
- Le site public et les notes publiées sur GitHub utilisent la même source.

## Installation vérifiée

- Le fichier téléchargé est vérifié par SHA-256 et ses dépendances Java et Fabric sont contrôlées.
- L’installateur attend la fermeture du processus Minecraft, conserve une sauvegarde et ne remplace pas une installation modifiée entre-temps.

DISPONIBILITÉ DES FONCTIONNALITÉS

État des modules

Une fonctionnalité peut être suspendue temporairement pour corriger un problème ou respecter une demande du serveur. La raison apparaît aussi dans le Companion. Les réglages personnels restent conservés.

Restrictions en cours

Chargement de la politique…

    Dans le jeu

    Les restrictions sont vérifiées chaque minute. Lorsqu’un module est suspendu, la raison apparaît dans ses réglages et ses actions s’arrêtent. Vos préférences sont conservées.

    Ce mécanisme est disponible à partir de la version 1.43.0-beta.1. Hors connexion, le Companion conserve la dernière information reçue. La réactivation d’un module ne lance aucune action automatiquement.

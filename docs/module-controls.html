État des modules

Une fonctionnalité peut être suspendue temporairement pour corriger un problème ou respecter une demande du serveur. La raison apparaît aussi dans le Companion. Les réglages personnels restent conservés.

    Administration

    Seul le compte GitHub propriétaire du dépôt, SpirtySprite, peut exécuter ces commandes. Le pseudo Minecraft ne sert pas de mot de passe. Aucun jeton administrateur n’est présent dans le mod ou sur cette page.

    1. Ouvrez les contrôles GitHub ci-dessous et connectez-vous au compte propriétaire.
    2. Cliquez sur Run workflow, choisissez main, puis le module et l’action disable ou enable.
    3. Pour suspendre un module, indiquez la raison destinée aux joueurs. Laissez les deux versions vides pour toucher toutes les versions compatibles, ou renseignez une plage inclusive.
    4. Lancez le workflow. Après sa réussite, les clients connectés récupèrent la politique lors de leur prochaine vérification, effectuée chaque minute.

    Ouvrir les contrôles protégés sur GitHub ↗

    À partir de 1.43.0-beta.1. Les versions 1.42.1 et antérieures ne contiennent pas ce mécanisme et ne peuvent pas être désactivées à distance. Une fois intégré, il reste utilisable dans les anciennes versions compatibles sans leur imposer une mise à jour.

    Si la vérification échoue, le client conserve la dernière politique valide mémorisée. Sans connexion ni politique déjà reçue, aucune nouvelle restriction ne peut être connue. La réactivation retire la restriction ; elle ne démarre pas automatiquement le minage ni une autre action.

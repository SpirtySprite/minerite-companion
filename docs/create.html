PARTAGER VOTRE PROJET

Le code d’un côté.
Le mod prêt à jouer de l’autre.

Pour proposer une extension Java, envoyez son code source en ZIP et son fichier JAR séparément. Ajoutez un nom, une description concrète et, si vous le souhaitez, une icône.

01

Préparez

Testez votre extension et préparez les deux fichiers de la même version.

02

Envoyez

Déposez votre projet sur le site. Aucun compte GitHub n’est nécessaire.

03

Partagez

Après validation, votre extension rejoint le catalogue de la communauté.
